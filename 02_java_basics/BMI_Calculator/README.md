# BMI Calculator — Health Category Classifier

## Overview

A command-line Java application that calculates Body Mass Index (BMI) using imperial or metric measurements. Returns the BMI value and a corresponding health category (underweight, normal, overweight, obese).

## Skills Demonstrated

- Class and object fundamentals
- User input handling and validation
- Conditional logic for health categorization
- Multi-class application structure

## Tech Stack

- Java (JDK 8+)

## How to Run

```bash
cd 02_java_basics/BMI_Calculator/src
javac *.java
java Main
```

Or open the project folder in IntelliJ IDEA and run `Main`.

## Highlights

- Supports both imperial (lbs/inches) and metric (kg/meters) systems
- BMI categories: underweight (< 18.5), normal (18.5–24.9), overweight (25–29.9), obese (≥ 30)
- Separates input validation, calculation, and display into dedicated classes
