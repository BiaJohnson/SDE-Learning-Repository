# Student Information System — Composite Data Structures

## Overview

A comprehensive Java management system for educational institutions. Handles student records, subject enrollment, and exam scheduling using multiple data structures and sorting/searching algorithms.

## Skills Demonstrated

- Composite data structures (lists, maps, custom collections)
- Multiple sorting algorithms (bubble sort, insertion sort)
- Binary search for efficient student lookup
- Object-oriented system design with layered components

## Tech Stack

- Java (JDK 8+)

## How to Run

```bash
cd 06_data_structures_&_Algorithms/Student_Information_System/src
javac *.java
java Main
```

Or open the project folder in IntelliJ IDEA and run `Main`.

## Highlights

- Student management: add/remove, search by ID or name, track subject enrollment
- Subject management with alphabetical sorting; exam schedule assignment
- Combines bubble sort, insertion sort, and binary search in a single application
