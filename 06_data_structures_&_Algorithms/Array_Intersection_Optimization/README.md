# Array Intersection Optimization — Multi-Strategy Comparison

## Overview

A Java program that finds the intersection of multiple sorted `ArrayList` collections using different approaches (nested loops, `HashMap`, `HashSet`). Compares time complexity to identify the most efficient strategy.

## Skills Demonstrated

- Array intersection algorithms
- `ArrayList`, `HashMap`, and `HashSet` usage
- Time complexity comparison and optimization
- Multi-approach benchmarking

## Tech Stack

- Java (JDK 8+)

## How to Run

```bash
cd 06_data_structures_&_Algorithms/Array_Intersection_Optimization/src
javac *.java
java ArrayListComparison
```

Or open the project folder in IntelliJ IDEA and run `ArrayListComparison`.

## Highlights

- Pre-built test sets with integers and strings for comparison
- Hash-based approaches achieve better performance than nested iteration
- Demonstrates practical trade-offs between simplicity and efficiency
