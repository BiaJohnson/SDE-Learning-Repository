# Binary Search — Sorted Array Lookup

## Overview

A Java implementation of the binary search algorithm for finding target elements in sorted integer arrays. Achieves O(log n) time complexity with O(1) space, including input validation and edge case handling.

## Skills Demonstrated

- Binary search algorithm (iterative approach)
- O(log n) time complexity analysis
- Input validation (null checks, sorted array verification)
- Edge case handling (empty arrays, single elements)

## Tech Stack

- Java (JDK 8+)

## How to Run

```bash
cd 06_data_structures_&_Algorithms/Binary_Search/src
javac *.java
java BinarySearch
```

Or open the project folder in IntelliJ IDEA and run `BinarySearch`.

## Highlights

- Returns the index of the target element, or -1 if not found
- Requires the input array to be sorted in ascending order
- Handles empty arrays, single-element arrays, and boundary conditions
