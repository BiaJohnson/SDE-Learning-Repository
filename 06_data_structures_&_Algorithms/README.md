# Data Structures & Algorithms

Java implementations of fundamental data structures and algorithms, including searching, sorting, stacks, queues, trees, maps, and complexity analysis.

## Skills Demonstrated

- Arrays, linked lists, stacks, and queues
- Binary trees and hash maps
- Sorting and searching algorithms
- Recursion and divide-and-conquer
- Big-O time and space complexity analysis

## Projects

| Project | Description | Skills |
|---------|-------------|--------|
| [Binary_Search](Binary_Search/) | Binary search on sorted arrays with O(log n) complexity | Binary search, Big-O |
| [Improved_BubbleSort](Improved_BubbleSort_Algorithm/) | Optimized bubble sort with early termination | Sorting, optimization |
| [Recursive_Fibonacci](Recursive_Fibonacci_Number/) | Fibonacci sequence via recursion and memoization | Recursion, optimization |
| [Array_Intersection_Optimization](Array_Intersection_Optimization/) | Optimized array intersection algorithm | Array algorithms, HashMap |
| [Even_Odd_Number_Processor](Even_Odd_Number_Processor/) | Processes numbers using custom stack and queue | Stack, queue, custom DS |
| [Postfix_Calculator](Postfix_Calculator/) | Evaluates postfix expressions with dual stack implementations | Stack, LIFO |
| [Maximum_Subarray](Maximum_Subarray/) | Finds maximum subarray sum using Kadane's algorithm | Kadane's algorithm, Big-O |
| [MergedTester](MergedTester/) | Tests HashMap merge behavior with overlapping keys | HashMap, map merging |
| [Generic_Binary_Tree](Generic_Binary_Tree_Implementation/) | Type-safe generic binary tree with Optional | Binary tree, generics |
| [Library_Search_Engine](Library_Search_Engine/) | Book catalog with search, sort, and serialization | Maps, sorting, persistence |
| [Student_Information_System](Student_Information_System/) | Student records using composite data structures | Composite DS, OOP |
| [Student_Registry_System](Student_Registry_System/) | Student registry with linked-list waiting list | Linked list, TreeMap |
