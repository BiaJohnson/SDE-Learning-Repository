# OOP Design Principles

Object-oriented Java applications demonstrating inheritance, encapsulation, polymorphism, and class hierarchy design through practical domain models.

## Skills Demonstrated

- Inheritance and class hierarchies
- Encapsulation and information hiding
- Polymorphism and method overriding
- Abstract vs concrete classes
- Separation of concerns

## Projects

| Project | Description | Skills |
|---------|-------------|--------|
| [Die_Game](Die_Game/) | Dice game simulation with class-based design | Randomization, inheritance |
| [Book_Information_Management_System](Book_Information_Management_System/) | Manages book records with OOP modeling | Data modeling, encapsulation |
| [Banking_System_Application](Banking_System_Application/) | Banking operations with account class design | Encapsulation, class design |
| [Virtual_Coffee_Machine_Project](Virtual_Coffee_Machine_Project/) | Polymorphic coffee beverage preparation system | Polymorphism, separation of concerns |
