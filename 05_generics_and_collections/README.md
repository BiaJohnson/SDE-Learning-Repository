# Generics & Collections

Java projects exploring type-safe generics, collection frameworks (List, Set, Map), and modular application design using reusable components.

## Skills Demonstrated

- Java generics and type parameters
- Collections framework (List, Set, Map)
- Wildcards and type safety
- Modular class design
- Inheritance with collection-based systems

## Projects

| Project | Description | Skills |
|---------|-------------|--------|
| [Generic_Value_Swapper](Generic_Value_Swapper_With_Display_Functionality/) | Swaps generic values with display functionality | Generics, type parameters |
| [Reverse_Array](Reverse_Array/) | Reverses user-entered arrays with modular design | Array manipulation, modularity |
| [Purchase_Tracking_System](Purchase_Tracking_System/) | Tracks purchases using collections | Collections, data tracking |
| [Vehicle_App](Vehicle_App/) | Vehicle management with autonomous vehicle hierarchy | Inheritance, polymorphism |

## Suggested Order

1. [Reverse_Array](Reverse_Array/) → 2. [Generic_Value_Swapper](Generic_Value_Swapper_With_Display_Functionality/) → 3. [Purchase_Tracking_System](Purchase_Tracking_System/) → 4. [Vehicle_App](Vehicle_App/)

## Getting Started

Compile and run from each project's `src/` directory: `javac *.java && java Main`. See individual project READMEs for details. Projects can also be opened directly in IntelliJ IDEA or Eclipse.
