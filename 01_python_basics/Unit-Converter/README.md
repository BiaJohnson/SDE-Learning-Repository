# Unit Converter — Weight & Volume Conversion Tool

## Overview

A CLI tool built for an artisan chocolate company that exports internationally. Converts between weight units (kilograms, pounds, ounces) and liquid units (litres, fluid ounces, pints, quarts) through an interactive menu.

## Skills Demonstrated

- Loops and conditional branching
- User input handling and menu-driven CLI design
- Unit conversion logic with fixed conversion rates
- Progressive feature extension (weight → volume)

## Tech Stack

- Python 3

## How to Run

```bash
cd 01_python_basics/Unit-Converter
python main.py
```

## Highlights

- Supports bidirectional weight conversions (kg ↔ lbs ↔ oz)
- Challenge extension adds liquid volume conversions (litres, fl oz, pints, quarts)
- Uses standard conversion constants (e.g. 1 kg = 2.20462 lbs, 1 litre = 33.814 fl oz)
