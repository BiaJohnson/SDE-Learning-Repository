# Nested Loop — Even/Odd Sum Calculator

## Overview

A Python program that uses nested `for` loops to pair even numbers (6–14) with odd numbers (5–13), compute their sums, and print each combination. Demonstrates nested iteration and accumulation patterns.

## Skills Demonstrated

- Nested `for` loops with `range()`
- Accumulation with running totals
- Formatted console output
- Iteration over complementary number ranges

## Tech Stack

- Python 3

## How to Run

```bash
cd 01_python_basics/Nested_Loop
python main.py
```

## Highlights

- Pairs each even number in range(6, 15, 2) with each odd number in range(5, 14, 2)
- Prints computations like `6 + 5 = 11`, `8 + 7 = 15`, etc.

## Sample Output

```
6 + 5 = 11
6 + 7 = 13
8 + 5 = 13
8 + 7 = 15
...
14 + 13 = 27
```
