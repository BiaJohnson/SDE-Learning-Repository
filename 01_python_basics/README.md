# Python Basics

Foundational Python projects covering control flow, iteration, functions, and an introduction to cloud integration. These exercises demonstrate core programming patterns before transitioning to Java.

## Skills Demonstrated

- Variables, loops, and conditionals
- Nested iteration and accumulation patterns
- Function design and progressive calculations
- External library integration (psutil, speedtest-cli)
- AWS serverless development (Lambda, S3, boto3)

## Projects

| Project | Description | Skills |
|---------|-------------|--------|
| [Unit-Converter](Unit-Converter/) | CLI tool for weight and volume unit conversions | Loops, conditionals, conversion logic |
| [Calculated_Bonus](Calculated_Bonus/) | Progressive quarterly bonus calculator for billable days | Functions, tiered calculations |
| [Nested_Loop](Nested_Loop/) | Sums even and odd numbers using nested loops | Nested iteration, accumulation |
| [Computer_Performance](Computer_Performance/) | Monitors CPU/RAM usage and internet speed | External libraries, system monitoring |
| [AWS_Lambda](AWS_Lambda/) | S3-triggered Lambda that processes student grade CSVs | AWS Lambda, S3, pandas, boto3 |

## Suggested Order

1. [Nested_Loop](Nested_Loop/) → 2. [Calculated_Bonus](Calculated_Bonus/) → 3. [Unit-Converter](Unit-Converter/) → 4. [Computer_Performance](Computer_Performance/) → 5. [AWS_Lambda](AWS_Lambda/)
