# Error Handling & File I/O

Java projects focused on reading and writing files, parsing structured data, and handling errors gracefully with try-catch blocks and try-with-resources.

## Skills Demonstrated

- Exception handling (try-catch, custom exceptions)
- File reading and writing (TSV, text files)
- Try-with-resources and resource management
- Defensive programming and input validation
- Object serialization

## Projects

| Project | Description | Skills |
|---------|-------------|--------|
| [Idea_Reader](Idea_Reader/) | Reads file contents into a string with proper resource cleanup | Try-with-resources, file I/O |
| [Menu_Reader](Menu_Reader/) | Parses and displays menu data from a file | File parsing, exceptions |
| [Grade_Reader](Grade_Reader/) | Processes student grades from TSV and generates a report | TSV parsing, file output |
| [Movie_Catalog](Movie_Catalog/) | Manages a movie catalog with file persistence | File I/O, catalog management |
| [Student_Management_System](Student_Management_System/) | Manages student rosters with try-catch error handling | Exception handling, OOP |
| [Student_Search_Program](Student_Search_Program/) | Searches student records with robust error handling | Search, exceptions |
| [Video_Settings_Serialization](Video_Settings_Serialization/) | Serializes and deserializes video settings objects | Object serialization |
